# Installing Atlas on Windows

Works on Windows 10 and 11 (64-bit).

## 1. Download
From the **[latest release](../../../releases/latest)**, download `Atlas-Setup-<version>-Windows.exe`.

## 2. Install
1. Double-click the downloaded file.
2. If you see **"Windows protected your PC"**, click **More info**, then **Run anyway**. Atlas isn't signed with a paid Microsoft certificate yet, so Windows asks you to confirm once.
3. Follow the installer. It adds Atlas to your Start menu and desktop.

## 3. Phone sync (optional)
The first time you turn on phone sync, Windows asks whether Atlas can use your network. Allow it on **Private networks** (your home Wi-Fi).

## Your data
- Saved to `Documents\Atlas\atlas-data.json` within a second of every change, with daily backups in `Documents\Atlas\Backups`.
- **Settings & data** lets you open the folder, back up, restore, or move the folder into **OneDrive** for an off-computer copy.

## Updating
Download and run the newer installer. It replaces the old version, and your data isn't affected.

## Uninstalling
Use **Settings → Apps → Atlas → Uninstall**. Your data stays in `Documents\Atlas` until you delete it yourself.
